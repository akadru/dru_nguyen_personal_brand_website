# Self-hosted fonts

Latin subsets downloaded from Google Fonts and loaded with `next/font/local` in `app/layout.tsx`, so production builds never need network access to Google.

- Outfit (variable, 400–800)
- Plus Jakarta Sans (variable, 300–800, normal + italic)
- Bebas Neue (400)

All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling them with this site.
