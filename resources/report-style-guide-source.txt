Color Usage Rules
Dark Jungle Green for all H1 headings and report titles. Never for backgrounds.
Myrtle Green is the only color used for H2 subheadings. H1 always Dark Jungle Green.
French Lime appears as accent lines, header borders, and callout borders. Use it generously - it is the brand signature in reports.
Body text defaults to #333333. Never pure black.
Table header rows use Dark Jungle Green background with French Lime or Anti-Flash White text.
Alternating rows use Anti-Flash White and Tea Green.

Second French Lime accent line (4pt, thinner).

Classification label ("Confidential" / "Internal") in Pastel Blue.
Header
Every content page includes a running header: "DRU NGUYEN" in Dark Jungle Green 8pt bold, followed by " | Report Title" in Pastel Blue 8pt. Bottom border: 2pt French Lime line with 4pt spacing below.
Footer
Every content page includes a running footer. Left: classification label in Pastel Blue 8pt. Right: page number in Pastel Blue 8pt. Top border: 1pt Tea Green line with 4pt spacing above.
Section Opener Pattern
Each major section follows this sequence: Heading 1 (Dark Jungle Green, 18pt bold), subtitle (Pastel Blue, 11pt italic), French Lime accent line (4pt bottom border, 4pt space), then content begins.
SECTION 4

Used for key insights and thesis statements that deserve visual emphasis. Dark Jungle Green text, 22pt bold, with a 12pt French Lime left border and 360 DXA left indent. One per section maximum. Reserve for the single most important takeaway.

4.4 Key Takeaway Pattern
Used after findings or analysis blocks. Bold label in Myrtle Green followed by regular Dark Jungle Green insight. Format: "Key Takeaway: [one to two sentence consequence or meaning of the finding]."
4.5 Arrow Insight Pattern
Used for takeaway statements beneath data points. Myrtle Green arrow followed by italic body text interpretation. One sentence is ideal; two is the maximum.
4.6 Lists
Bullet lists use the standard bullet character via numbering config - never unicode bullets inserted manually.
Numbered lists use decimal format. Both indent 720 DXA with 360 DXA hanging.
Each new numbered list needs a unique reference to restart at 1.
SECTION 5
Chart and Graphic Standards
General Chart Rules
All charts use the brand color palette. Primary fills use Myrtle Green. Risk/contrast uses French Lime. Positive/growth uses Tea Green.
White background on all charts (#FFFFFF). Never colored chart backgrounds.
Axis labels in Pastel Blue. Data labels in Dark Jungle Green bold.
Grid lines: Tea Green, thin (0.5 to 0.8pt).
Export at 200 DPI as PNG. Embed at widths between 320 and 520px.
Remove all chart borders and unnecessary axis spines.

SECTION 6
Voice and Writing Style
How Dru Nguyen reports sound. Every report Claude produces must pass these filters.
Tone Principles
Direct, not diplomatic. 
State findings plainly. "Revenue is the highest-risk area" not "there may be opportunity to improve revenue processes."
Precise, not academic. 
Use specific language. "Level 2 - Assisted" not "a moderate level of maturity."
Honest about risk. 
Name what is at stake. Use Tea Green or light pink callouts for genuine warnings.
Action-oriented. 
Every section should imply or state what needs to change. No section ends without a direction.
Concise. 
Body text paragraphs rarely exceed 3 sentences. If it is longer, break it up.
Hard Rules
Never use em dashes. Use a colon or rewrite the sentence.
Never use corporate jargon. No "synergy," "leverage," "circle back," or "deep dive."
Never be overly formal or stiff. Scholarly Warrior is confident, not cold.
Never lose the identity. Every report should sound unmistakably like Dru Nguyen.
Use smart quotes. Never straight quotes.
Use arrows for flow sequences: Research > Synthesis > Decision.
Abbreviations: define on first use, then use freely. Common exceptions: AI, ROI, KPI.
Structural Patterns
Finding > Evidence > Implication. State the finding, support it briefly, then give the so-what.
Bold lead-in + regular detail. Start paragraphs with a bold phrase that summarizes, then explain.
Callout the thesis. Each section's most important sentence belongs in a callout or highlight box.
End with a "Bottom Line" box when a section covers complex ground.

Implementation Notes
Use docx-js (npm install -g docx) for programmatic generation. Never manually insert unicode bullets.
Table widths must always use WidthType.DXA - never percentage (breaks in Google Docs).
Set both columnWidths on the table AND width on each cell - they must match.
Use ShadingType.CLEAR for all table shading - never SOLID (creates black backgrounds).
Charts: generate with matplotlib at 200 DPI, white background, brand colors. Embed as PNG.
Each numbered list needs its own unique reference to restart numbering independently.
PageBreak must always be inside a Paragraph element.
Never use tables as horizontal rules - use Paragraph border bottom instead.
